# Critical Support Example

For the fixed two-module SAOR system, only three prime-presence bits are needed beyond `(D4,D5)`:

`eps5`

`eps7`

`eps11`.

Each is necessary. Equal-`(N,S)` witnesses differing in exactly one bit admit explicit future contexts that produce different masking responses.

No prime `>=13` requires an individual support bit in the sharp classifier.

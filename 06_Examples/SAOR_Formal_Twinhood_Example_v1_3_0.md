# Formal Twinhood Example

For one module and context `E`, construct the `P`-transfer and `S`-transfer neighbourhoods of the two contextual roots.

The roots are masked exactly when their external neighbour sets agree in both graphs. A candidate realization that is adjacent to one root and not the other is an explicit unmasking certificate.

The direct definition-level verifier implements this definition without calling the closed-form masking functions.

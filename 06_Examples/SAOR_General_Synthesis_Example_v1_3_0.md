# General Synthesis Example

For an admissible base pair:

1. verify equal arity, sum, and product;
2. verify Prime Cover and Atom Deficit;
3. compute exclusive factor values;
4. fix the opposite-root forbidden set for each direction;
5. enumerate possible smallest safe fillers `q`;
6. construct a permanent odd increment and threshold `C_q`;
7. enumerate only the residuals below `C_q`;
8. collect the low primes that can affect those residuals.

The result is an exact masking classifier based on `N`, `S`, and finitely many support bits.
